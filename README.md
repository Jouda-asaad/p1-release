# P1 Releases

Signed installers for P1, the self-hosted file sync by Unmanned Systems Engineering. There is no source code here: each GitHub Release holds the Windows installer, the Mac tarballs, the MCP tool, and a `manifest.json` signed with P1's release key (`manifest.json.sig`).

P1 Sync updates itself from here to the Release its own Server runs, and installs nothing whose signature or hash doesn't check out. To install P1 Sync, use the download link on your P1 Server.
